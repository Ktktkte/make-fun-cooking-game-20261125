Entry for make.fun's "Make the best cooking game" bounty: **Rush Hour Kitchen** — an original order-rush cooking game. Orders fly in on the board with a countdown; click ingredients on the counter (or press 1-6) to build each dish on the plate, then serve before the timer runs out. Correct dish: +100 and a tip. Wrong dish: -15. Expired order: -25. One 3-minute shift.

## Play it

```sh
# serve game/ (any static server), then open http://localhost:8080
python3 -m http.server 8080 --directory game
```

## Hand it in

```sh
MAKEFUN_OUTPUT_DIR=out node main.ts
```
